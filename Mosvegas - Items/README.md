# MosVegas Items — Fabric 1.20.4

Создатели мода: telegram **@merami_studio**  
Автор: telegram **@merami19**

Универсальные расходуемые предметы с настройкой через JSON: еда, напитки, алкоголь, табак и другие категории. Пиво использует предоставленные модель, текстуру и логотип. Перекус и энергетик используют ванильные текстуры как примеры; сигарета — простую демонстрационную модель. Кроме того, в мод встроены 59 видов еды и напитков с 3D-моделями и 3D-вид ванильной еды (см. «Еда и группы во вкладке»).

## Установка

В папку `mods` клиента и сервера положите `mosvegas-items-1.1.1.jar`, Fabric API **0.97.2+1.20.4** и GeckoLib **4.4.4 для Fabric 1.20.4**. Нужен Fabric Loader 0.15.11 или новее (сборка и первоначальный запуск — на **0.19.5**), Minecraft **1.20.4**, Java **17+**. Установочный комплект содержит папку `mods` с модом и обеими библиотеками. При обновлении замените старый JAR мода.

При первом запуске появляются `config/mosvegas_items/consumables` с четырьмя JSON-примерами и встроенной едой в папке `food`, а также `config/mosvegas_items/resources/assets/mosvegas_items` для ресурсов. Эти папки можно редактировать без изменения JAR. После изменения JSON перезапустите игру/сервер. `/reload` не создаёт новые item IDs. Ресурсы можно обновить F3+T.

На сервере и у каждого игрока должен быть одинаковый набор JSON и тот же мод. Ресурсы нужны на клиентах; можно раздать папку `resources` как обычный resource pack. Мод не загружает конфигурацию автоматически с сервера. Не удаляйте и не переименовывайте IDs предметов, уже используемых в сохранении. Для тестов используйте отдельный мир.

## Новый предмет без кода

1. Скопируйте JSON из `consumables`, задайте уникальный `id`, имя и параметры.
2. Для 3D: экспортируйте Blockbench-проект **GeckoLib Animated Model** в `.geo.json`, а анимацию в `.animation.json`. Поместите файлы в `resources/assets/mosvegas_items/geo`, `animations` и PNG в `textures/item`.
3. Укажите `model`, `texture`, `animation_file`, при необходимости `idle_animation` и `use_animation` (точные имена из анимационного файла).
4. Перезапустите клиент и сервер. Предмет появится в творческой вкладке MosVegas Items и в `/give @s mosvegas_items:ID`.

Для обычной 2D-текстуры оставьте `model` пустым или не указывайте его. Используйте `texture: "mosvegas_items:item/my_item"` (файл `textures/item/my_item.png`). Можно указать полный путь `textures/item/my_item.png`. Minecraft item model JSON создаётся автоматически. Для собственных положений в руке положите `models/item/ID.json` в `resources`: он заменит автоматически созданный.

## Еда и группы во вкладке

Встроенная еда лежит в `config/mosvegas_items/consumables/food`: пицца, бургеры, фастфуд, мясо, выпечка, пончики, капкейки, маффины, пироги, фрукты, газировка, соки, молоко и вода, чай и кофе, пиво, вино и коктейли. Эти JSON можно менять и удалять, как любые другие. Новые встроенные предметы из следующих версий мода копируются в конфигурацию один раз; удалённый файл больше не появляется. Если такой ID уже есть в вашей конфигурации, встроенный предмет не добавляется. Список скопированных файлов хранится в `.initialized`.

Похожие предметы занимают во вкладке один слот с красным уголком. Клик по нему открывает красный список вариантов; предмет из списка берут так же, как в любой вкладке: клик — одна штука, Shift+клик или колёсико — стак, клавиши 1–9 — в хотбар, Q — выбросить. Esc или клик мимо закрывает список. Поиск творческого режима и `/give` находят каждый вариант отдельно. Группа задаётся параметром `group`, порядок — `order` (см. «Параметры»).

Модели еды — обычные модели предметов Minecraft (`assets/mosvegas_items/models/item/ID.json`); положение в руке и размер в инвентаре заданы авторами моделей. Чтобы изменить их, положите свой `models/item/ID.json` в `resources`.

Набор ресурсов **MosVegas: 3D-еда** встроен в мод и делает трёхмерными 42 ванильных продукта: яблоко, хлеб, мясо, рыбу, супы, пироги и другие. Он включён по умолчанию и отключается в «Настройки → Наборы ресурсов». Ванильные текстуры он не заменяет, поэтому плоские предметы с ванильными текстурами (например, «Перекус») выглядят как прежде. Модели набора: 3D Foods Resourcepack, автор HatsuyaDev.

`use_action` управляет движением предмета от первого лица и руки персонажа от третьего лица: `drink` — питьё, `eat` — еда, `smoke` — затяжка, `none` — без позы. Поза работает для основной и второй руки, включая леворукого персонажа, плавно поднимает руку и опускает её в конце употребления. Другие игроки видят те же движения: все клиенты считают позу по общему графику употребления. Для 3D-предметов от первого лица видна рука со скином игрока. Анимации GeckoLib из `use_animation` дополнительно двигают кости самой модели.

Затяжка: рука подносит сигарету фильтром к губам, уголёк разгорается и бумага прогорает, рука опускается, затем игрок выдыхает дым по направлению взгляда. От уголька всё время поднимается тонкая струйка дыма. Питьё: банка подносится краем к губам и наклоняется всё сильнее, голова слегка запрокидывается.

У 3D-модели точка хвата должна находиться в `(0, 0, 0)`, верх банки или уголёк — по оси `+Y`. В примерах центр банки расположен в начале координат, сигарета начинается фильтром на `Y=-1`, заканчивается угольком на `Y=7`. При затяжке к губам подносится фильтр, уголёк направлен наружу. Не добавляйте стандартный поворот Minecraft на 90° в `display`: поворот руки уже выполняет мод. Для своих размеров настройте `scale` и `translation` в `models/item/ID.json`; у типовых предметов отдельные шаблоны `consumable` и `consumable_smoke`.

```json
{
  "id": "my_drink",
  "name": "Мой напиток",
  "description": "Описание предмета",
  "category": "drink",
  "use_action": "drink",
  "model": "geo/beer.geo.json",
  "texture": "textures/item/beer.png",
  "animation_file": "animations/consumable.animation.json",
  "use_animation": "animation.beer.use",
  "use_time": 32,
  "hunger": 2,
  "saturation": 0.3,
  "uses": 3,
  "stack_size": 16,
  "cooldown": 40,
  "always_edible": true,
  "remainder": "minecraft:glass_bottle",
  "sound": "minecraft:entity.generic.drink",
  "finish_sound": "minecraft:entity.player.burp",
  "sound_volume": 0.6,
  "sound_pitch": 1.0,
  "sound_interval": 8,
  "particles": {"id": "minecraft:happy_villager", "count": 2, "interval": 8, "spread": 0.07, "speed": 0.01},
  "effects": [
    {"id": "minecraft:speed", "duration": 400, "amplifier": 1, "chance": 1.0, "show_particles": true, "show_icon": true},
    {"id": "minecraft:nausea", "duration": 100, "amplifier": 0, "chance": 0.15}
  ]
}
```

## Параметры

- `id`: постоянный ID, строчные латинские буквы, цифры, `_`, `/`, `-`. `enabled: false` отключает регистрацию при следующем запуске.
- `group`: ID группы — строчные латинские буквы, цифры, `_`. Предметы с одинаковой группой занимают во вкладке один слот, в нём показан первый по порядку. Название группы — ключ перевода `group.mosvegas_items.ГРУППА` в `lang/ru_ru.json` и `en_us.json`; без перевода показывается сам ID. Группа из одного предмета — обычный слот.
- `order`: целое число, место во вкладке: меньше — раньше, при равенстве — по `id`. По умолчанию 0. Встроенная еда использует 100–252.
- `name`, `description`: обычный текст или ключ перевода. Переводы в `lang/ru_ru.json` / `en_us.json`. Перенос строки в описании — `\n`.
- `category`: `food`, `drink`, `alcohol`, `tobacco`, `other`; категория сама по себе не выдаёт эффекты.
- `use_action`: `eat`, `drink`, `smoke`, `none`. По умолчанию выбирается по категории. 3D-модели подносятся ко рту и от первого, и от третьего лица; у плоских предметов от первого лица ванильные движения, от третьего лица рука подносит предмет ко рту. Анимации костей GeckoLib задаются отдельно.
- `use_time`, `cooldown`, `sound_interval`, `particles.interval`, `effects.duration`: тики, **20 = 1 секунда**.
- `hunger`: 0–20, одна единица = половина значка еды. `saturation`: множитель Minecraft; добавляется `hunger × saturation × 2`, максимум до текущего уровня еды.
- `uses`: 1–10000 порций на единицу. Частично использованный предмет отделяется от стака и остаётся в активной руке; остальные возвращаются в инвентарь, при отсутствии места выпадают. Частично использованные единицы не объединяются. Полоска прочности появляется после первой порции и показывает остаток; у нетронутых предметов её нет. В творческом режиме расход определяется `consume_in_creative`.
- `consume_in_creative`: тратить порции и в творческом режиме. По умолчанию `false`; у сигареты, пива, энергетика и всей встроенной еды — `true`.
- `stack_size`: 1–64. `cooldown` действует на все предметы с тем же ID.
- `always_edible`: разрешить использование при полном голоде. По умолчанию `false` для `eat`, `true` для остальных. Встроенную еду можно есть и сытым.
- `remainder`: предмет, выдаваемый после последней порции, либо пустая строка.
- `discard`: что делать с пустым предметом после последней порции.
  - `throw`: пустая банка остаётся в руке. Её выбрасывают обычной клавишей «Выбросить предмет» (Q), и она летит туда, куда смотрит игрок: взгляд вверх — бросок высоко, вперёд — далеко. Пустые банки складываются в стопку и не используются повторно.
  - `drop`: окурок сам падает на пол у ног после последней затяжки.
  - `none`: предмет просто исчезает.

  По умолчанию 3D-напиток без `remainder` получает `throw`, 3D-сигарета — `drop`, остальные — `none`. Выброшенные банки и окурки декоративные: их нельзя подобрать, они не сохраняются в мире и исчезают через минуту. Окурок ещё 5 секунд тлеет и дымит. При смерти пустые банки выпадают обычными предметами.
- `start_sound`: включает открытие. Закрытая банка сначала открывается отдельным коротким использованием: вторая рука, если она свободна, тянет язычок, звук звучит в момент щелчка. Открывается только одна единица, остальные в стопке остаются закрытыми. Если отпустить кнопку раньше, банка остаётся закрытой. Открытие не тратит порцию и не запускает `cooldown`.
- `open_time`: длительность открытия в тиках, 1–72000, по умолчанию 20.
- `sound` во время использования, `finish_sound` после завершения. Пустая строка отключает звук. `sound_volume`: 0–4; `sound_pitch`: 0.1–2.
- Собственный звук: OGG в `resources/assets/mosvegas_items/sounds`, объявление в `sounds.json`, затем ID `mosvegas_items:my_sound` в JSON предмета.
- `particles`: `false` или объект. Поддерживаются простые типы частиц без дополнительных данных (`smoke`, `happy_villager`, `flame`, и т.д.). Типы `dust`, `item`, `block` требуют дополнительных данных и не поддерживаются этим полем.
  - Для `smoke` частицы — это выдох после затяжки. Они вылетают изо рта по направлению взгляда со скоростью `speed`. По умолчанию используется `mosvegas_items:exhaled_smoke`: светлое облако, которое расплывается и тает.
  - Тонкий дым от уголька (`mosvegas_items:cigarette_smoke`) идёт всегда и от этого поля не зависит.
  - Для остальных действий частицы появляются у рта во время использования.
- `effects`: любое число независимых эффектов с ID из Minecraft или установленных модов. `amplifier: 0` = уровень I, `1` = II. `chance`: 0–1, где 0 никогда, 1 всегда. Мгновенные эффекты применяются сразу. `ambient`, `show_particles`, `show_icon` настраиваются отдельно. Повторные эффекты объединяются по правилам Minecraft.
- `model`, `texture`, `animation_file`: полный ID `namespace:path` или путь в `mosvegas_items`. Для GeckoLib texture указывается как `textures/item/NAME.png`.
- `idle_animation`, `use_animation`: пустая строка отключает анимацию. Указанная анимация зацикливается на время соответствующего состояния и сбрасывается при прекращении использования.

Неверные JSON или дубли IDs останавливают загрузку с указанием файла, чтобы предметы не исчезли из мира молча. Неизвестные эффекты, остатки и неподдерживаемые частицы выявляются при запуске сервера/мира.

## Сборка и запуск

На этой машине `launcher-java.ps1 build` собирает проект, `test-client.bat` запускает тестовый Minecraft с сохранениями и конфигурацией в папке `run/client` (`gradlew runServer` — сервер в `run/server`). Оба используют Java из Minecraft Launcher (Java 21 delta), байткод мода совместим с Java 17. `gradlew` входит в проект; на другой машине укажите JAVA_HOME (JDK 21 для Loom 1.11) и выполните `gradlew build` / `gradlew runClient`.

Готовый мод: `build/libs/mosvegas-items-1.1.1.jar`. `*-sources.jar` — исходники, его не кладут в mods.

`launcher-java.ps1 releaseZip` собирает мод, выполняет проверки и создаёт два архива в `dist`:

- `MosVegas-Items-1.1.1-Fabric-1.20.4.zip` — мод и необходимые библиотеки для установки.
- `MosVegas-Items-1.1.1-Sources.zip` — полный проект для разработки без кешей, сборок, логов и игровых данных.

`launcher-java.ps1 check` отдельно проверяет JSON-конфигурацию, геометрию рук и refmap миксинов в готовом JAR (без него мод работает в тестовом клиенте, но падает при запуске из обычного лаунчера). `launcher-java.ps1 verifyServer` проверяет употребление предметов на изолированном тестовом сервере в `build/verification-server`; `releaseZip` запускает и эти проверки. Тесты лежат в `tests`: `gametest` — проверки на сервере, `verification` — проверки JSON и геометрии; в игровой JAR они не включаются. Вспомогательные скрипты (конвертация звуков, обновление примеров конфигурации) — в `tools`. Встроенная инструкция автоматически берётся из этого README; второй копии в исходниках нет.

Большую часть старого JAR занимала иконка 1254×1254 (1,41 МБ). В версии 1.0.1 она уменьшена до 128×128 (33 КБ); игровые текстуры не уменьшались. Fabric API и GeckoLib поставляются отдельно и занимают около 3,2 МБ вместе. Папки `.gradle`, `build`, `run` и игровые сохранения не являются исходным кодом и не входят в чистый архив.

Встроенная сигарета укорачивается во время каждой затяжки, после последней окурок падает на пол. Пиво сначала открывается, затем в нём четыре глотка; пустую банку выбрасывают клавишей Q. В энергетике три глотка, после последнего остаётся стеклянная бутылка (`remainder`). Звуки банки и питья взяты из реальных записей; авторы, источники и лицензии указаны в `AUDIO_CREDITS.md`, который входит в JAR и архивы.
