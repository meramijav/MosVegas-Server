# MosVegas Casino — блэкджек с живыми крупье (Fabric 1.20.4, Java 21)

Мод живого казино: полукруглые столы как в live-казино (Evolution: Blackjack Classic, Speed, Infinite, Free Bet, Salon Privé),
анимированные крупье (мужчины и женщины) приходят на смену, садятся, тасуют, раздают карты, реагируют эмоциями и уходят на перерыв.
Деньги — через **Mosvegas Core (RpCore)**: банковский счёт или наличные. Рулетка и слоты подготовлены (математика и точки подключения).

## Установка

Сервер **и** клиенты (у мода есть блоки, сущности и рендер):

| Мод | Где взять |
|---|---|
| `mosvegas-casino-1.0.0.jar` | `build/libs/` после сборки |
| GeckoLib 4.4.x для Fabric 1.20.4 | уже стоит на сервере для транспорта (`libs/geckolib-fabric-1.20.4-4.4.4.jar`) |
| Fabric API 0.97+ | обязательно |
| Mosvegas Core 0.0.4 | только сервер (на клиенте тоже можно), необязателен: без него — тестовый кошелёк |

Java 21. Первый запуск создаёт `config/mosvegas-casino.json`.

## Как это работает в игре

1. Админ берёт стол: творческая вкладка **«MosVegas Казино»** или `/casino give <стиль>` (или `/casino place <стиль>` — ставит перед собой).
   Стол ставится **лицом к игрокам**: крупье садится с дальней стороны. Классика/Speed/Infinite — 5×3 блока, 7 боксов;
   Free Bet и Salon Privé — 3×2 блока, 5 и 3 бокса. Столы неразрушимы в выживании (ломает только админ в креативе).
2. Задайте **вход для персонала**: встаньте у двери «только для персонала» и выполните `/casino table entrance here`
   (глядя на стол или стоя рядом). Оттуда крупье приходит и туда уходит. По умолчанию — 4,5 блока за спиной крупье.
3. Игрок кликает ПКМ по столу у нужного бокса → садится на стул. Если бокс занят — ставит **за спиной** (до 3 человек на бокс,
   в Infinite — до 8). Как только кто-то сел, **вызывается крупье**: он идёт от входа, садится, здоровается, тасует шуз.
4. **Ставки — как в live-казино**: меню стола открывается само, когда объявляют ставки. Над крупье — «Делайте ваши ставки»,
   таймер (15 с) и ряд фишек 100…100 000 с кнопками «Отменить» и «Повторить» / «×2». Ставка делается **кликом по кругу на
   самом столе**: ЛКМ по своему основному кругу или по кругу побочной ставки (Perfect Pairs, 21+3, Hot 3, Bust It — по типу
   стола) — фишка летит из руки на сукно. Свои круги подсвечены, круг под курсором — ярко, рядом подсказка с суммой.
   ПКМ — убрать последнюю фишку, колесо мыши или 1…9 — номинал фишки. Затем «Раздать» (или пробел).
   Минимум для начала — 1 игрок против дилера (`minPlayers`).
5. Крупье раздаёт карты руками (см. «Что крупье делает руками»), закрытая карта дилера, страховка при тузе.
   Проигравшие побочные ставки крупье забирает сразу после раздачи, выигравшие — оплачивает (с сообщением в чате).
   Решения — круглые кнопки внизу: **+ Взять / − Хватит / 2× Удвоить / ⇆ Сплит / ½ Сдаться** (или H / S / D / P).
   Справа вверху — рука дилера и ваша рука с суммой очков, слева внизу — баланс и общая ставка.
   Клавиша **[B]** — открыть меню стола, **Shift** — встать.
6. Дилер добирает до 17, выплаты (блэкджек 3:2, страховка 2:1, побочные по таблицам), фишки выигрыша, сбор карт в сброс.
   Итог показывается **по частям**, чтобы выигрыш руки не путался с побочной ставкой: над крупье — результат руки
   («Вы выиграли +5 000 ₽»), под ним — «Побочные ставки: −5 000 ₽ · Итого за раунд: 0 ₽»; в чате — то же построчно
   («Ваша рука: 18 против перебора у дилера (23) — выигрыш +5 000 ₽», «Побочные ставки: −5 000 ₽», «Итого за раунд: 0 ₽»).
   Выигрыш зачисляется на банковский счёт (или наличными — см. `economy.source`), даже если игрок уже вышел.
7. **Смены «по КД»**: через `shiftMinutes` минут работы между раундами приходит другой крупье, старый говорит «Меня сменяет …»,
   встаёт, машет и уходит на перерыв `breakMinutes`. Пустой стол крупье покидает через `idleLeaveSeconds`.

### Виды столов (варианты игры)

| Стиль | Вариант | Особенности |
|---|---|---|
| `classic_black` | Classic | 7 боксов, 6 колод, европейский без закрытой карты, дилер стоит на 17, ставки за спиной до 3 человек, PP + 21+3 |
| `speed_green` | Speed | Все боксы решают **одновременно**, карта уходит тому, кто решил раньше; короче таймеры |
| `infinite_grey` | Infinite | **Без ограничения игроков**: все получают одни и те же стартовые карты, каждый решает за себя, общая карта раздаётся всем, кто взял; 6 карт без перебора — автоматическая победа; PP, 21+3, Hot 3, Bust It |
| `free_bet_purple` | Free Bet | Бесплатный дабл на жёстких 9/10/11 и бесплатный сплит (кроме десяток), дилер с 22 — ничья |
| `salon_prive` | Classic VIP | 3 бокса, высокие лимиты 5 000 — 1 000 000 |

Любое правило меняется в `styles.<id>.rules` (колоды, `dealerHitsSoft17`, `holeCard`, `blackjackPayout`, `doubleOn`, `maxHands`,
`surrender`, `insurance`, `sixCardCharlie`, `freeBet`, `dealer22Push`, `sideBets`, `turnMode` SEQUENTIAL/PARALLEL/COMMON,
`maxBettorsPerBox`, таймеры `betSeconds`/`decisionSeconds`, скорость раздачи `cardTicks`). Можно добавить свой стиль (новый ключ в `styles`).

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/casino` | все | подсказка |
| `/casino leave` | все | выйти из-за стола |
| `/casino give <стиль>` / `/casino place <стиль>` | админ | выдать / поставить стол |
| `/casino table info` | админ | состояние стола, лимиты, крупье, статистика (ставки/выплаты/раунды) |
| `/casino table open\|close` | админ | закрыть стол: ставки раунда возвращаются, крупье уходит |
| `/casino table style <стиль>` | админ | сменить стиль (того же размера) между раундами |
| `/casino table entrance here\|reset` | админ | вход персонала для крупье |
| `/casino table limits <мин> <макс>\|reset` | админ | лимиты конкретного стола |
| `/casino dealer list\|call\|dismiss` | админ | кто где работает/на перерыве; вызвать; отпустить |
| `/casino dealer change` | админ | пересменка у ближайшего стола: после текущего раунда крупье прощается и уходит, его место занимает свободный коллега |
| `/casino stats` | админ | доход казино по столам |
| `/casino reload` | админ | перечитать конфиг (правила применяются между раундами) |
| `/casino money <игрок> <сумма>` | админ | только тестовый кошелёк без Mosvegas Core |

Права: OP уровня 3 или нода `mosvegas.casino.admin` через Mosvegas Core (`adminPermission`). Стол — действие `interact`
для зон Mosvegas Core: в публичной зоне казино оно разрешено по умолчанию.

## Деньги (Mosvegas Core)

`economy.provider`: `auto` (ядро, если установлено) / `rpcore` / `dev`.
`economy.source`: `bank` — банковский счёт (`EconomyService.debit/credit`), `cash` — купюры в инвентаре (`RpItems`), `cash_then_bank`.
Ставка списывается сразу при нажатии фишки; при выключении сервера, закрытии стола, уходе крупье или разрушении стола
все неразыгранные ставки возвращаются. Выплата игроку офлайн идёт на банковский счёт.

## Крупье и скины

`dealers.profiles` — список крупье (6 по умолчанию: Анна, Мария, Елена — женские; Максим, Артём, Давид — мужские).

```json
{ "id": "kate", "name": "Катя", "gender": "female", "skin": "player:Notch", "styles": [] }
```

`skin` принимает:
* `mosvegas_casino:textures/entity/dealer/kate.png` — PNG 64×64 в ресурспаке (стандартная развёртка скина Minecraft);
* `https://сайт/скин.png` — прямая ссылка на PNG (клиенты скачают и закэшируют в `.minecraft/mosvegas_casino/skins`);
* `player:Ник` — скин аккаунта Minecraft (сервер берёт его через Mojang API).

`gender: female` → модель с тонкими руками (Alex), `male` → классическая (Steve). `styles` — за какими столами работает (пусто — за всеми).
Свою 3D-модель/анимации конкретного крупье можно задать полями `model` / `animations` (id GeckoLib-файлов).

Настройки смен: `shiftMinutes`, `breakMinutes`, `idleLeaveSeconds`, `alwaysStaffed` (крупье сидит даже без игроков),
`leaveWithoutReplacement`, `walkSpeed`, `speechBubbles` (облачко реплик), `chatRadius`, `showNameTags`, `title`,
`voiceRadius` (на каком расстоянии слышен голос, 0 — без голоса), `fidgetSeconds` (как часто крупье перебирает фишки, кивает,
задумывается в ожидании; 0 — никогда).
Все реплики крупье и сообщения игрокам — в `phrases` (плейсхолдеры `{player}`, `{dealer}`, `{value}`, `{amount}`…).

### Что крупье делает руками

Карты и фишки не летают сами: клиент запускает движение руки крупье и ведёт предмет по реальному положению его ладони
(кости `leftHand` / `rightHand` модели):

* **раздача** — левая рука вынимает карту из башмака; на боксы слева от крупье кладёт её сама, на остальные передаёт правой
  руке; карта ложится и скользит по сукну на место, переворачиваясь рубашкой вниз (закрытая карта дилера остаётся закрытой);
* **выплата** — по очереди с правой стороны крупье: проигрышные ставки рука забирает в лоток, выигрыш выносит из лотка и
  ставит рядом со ставкой; после раунда игроки «забирают» свои фишки к себе;
* **сбор карт** — обе руки сгребают карты от краёв к центру, сводят их в стопку, правая рука кладёт стопку в сброс;
* **жесты** — голова поворачивается к боксу, куда идёт карта; на «ваше решение?» крупье показывает ладонью на игрока;
  кивает на ставки, кланяется новому игроку, хлопает при блэкджеке, качает головой при переборе, в ожидании перебирает фишки.

### Голос

Крупье говорят вслух: 204 реплики в `assets/mosvegas_casino/voice/female/` и `.../male/` (синтез голосами Windows
«Ирина» и «Павел»). Во время речи у крупье двигаются губы, крупье моргают. Голос идёт от крупье, громкость — ползунок
«Голос/речь» в настройках звука. Набор голоса задаётся в профиле: `"voice": "female"` (по умолчанию — по полу),
`"voicePitch": 1.05` — высота голоса, чтобы два крупье звучали по-разному.

Сервер просит сначала самый точный файл, затем общий: `dealer_total_19` → `dealer_total`, `your_turn_7_17` → `your_turn`,
`greeting_anna` → `greeting`, `handover_maria` → `handover`. Любой файл можно заменить живой записью в ресурспаке
(`voice/<набор>/<ключ>.ogg` или `.wav`, моно или стерео), а свой набор голоса — положить в новую папку
`voice/<имя>/` и указать `"voice": "<имя>"` в профиле. Перегенерировать озвучку: отредактировать
`tools/voice/phrases.txt` и запустить `tools/VoiceGen.ps1` (Windows с русскими голосами).

## Замена моделей, анимаций, текстур, звуков

Всё — обычные ресурсы `assets/mosvegas_casino/…`, заменяются ресурспаком (или прямо в jar) **с теми же именами файлов**:

| Что | Файл | Чем править |
|---|---|---|
| Модель стола | `geo/block/blackjack_table_<стиль>.geo.json` | Blockbench, плагин GeckoLib (Bedrock/GeckoLib Block) |
| Текстура стола (сукно с надписями + материалы) | `textures/block/table/<стиль>.png` (1024×1024: сверху сукно, ниже образцы материалов) | любой редактор |
| Анимация стола (необязательна) | `animations/block/blackjack_table.animation.json`, анимация `animation.table.idle` | Blockbench |
| Модель крупье | `geo/entity/dealer_wide.geo.json`, `dealer_slim.geo.json` (кости `root, body, head, rightArm, leftArm, rightLeg, leftLeg`, пустые `rightHand`/`leftHand` в ладонях, `mouth`, `eyelids`) | Blockbench |
| Анимации крупье | `animations/entity/dealer.animation.json` | Blockbench |
| Скины крупье | `textures/entity/dealer/<id>.png` | редактор скинов |
| Карты | `textures/card/<масть>_<ранг>.png` (spades/hearts/diamonds/clubs, a,2..10,j,q,k), рубашка `back.png` или `back_<стиль>.png` | любой |
| Фишки | `textures/chip/chip_<номинал>.png` (круг на прозрачном фоне; по краю — полоски, они же идут на ребро) | любой |
| Звуки | `sounds.json` (`card_deal`, `card_flip`, `chip_place`, `chip_stack`, `shuffle`, `knock`, `cards_collect`, `win`, `blackjack`) | свои .ogg |
| Голос крупье | `voice/<набор>/<ключ>.wav` или `.ogg` (см. «Голос») | запись / TTS |

Анимации крупье (имена `animation.dealer.<id>`, всего 41):
* циклы: `idle`, `walk`, `sit`, `talk` (голова во время речи);
* движения рук, которые клиент проигрывает вместе с картами и фишками: `deal_0`…`deal_6` (раздача в 7 направлений, от левой
  стороны крупье к правой), `deal_self`, `reach_0`…`reach_6` (выплатить/забрать ставку), `collect`;
* жесты от сервера: `point_0`…`point_6`, `flip`, `peek`, `shuffle`, `present` («делайте ставки»), `wave`, `bow`, `nod`, `clap`,
  `shake_head`, `shrug`, `think`, `tidy`, `sit_down`, `stand_up`.

Если перерисовываете движения рук в Blockbench, сохраните ключевые моменты (когда рука берёт и отпускает карту) или поправьте
их в `ru.mosvegas.casino.client.state.Choreo`. Стандартные анимации строит `tools/AssetGen.java` с расчётом поз рук
(обратная кинематика от плеча до башмака, лотка, боксов).

Важно для своих моделей стола: позиции боксов, стульев, шуза и карт считаются из радиуса стола
(`ru.mosvegas.casino.table.TableGeometry`): MEDIUM — радиус 1,45 блока, LARGE — 2,4; центр полукруга в 0,45 блока
за мастер-блоком к крупье, поверхность сукна на высоте 14/16. Стандартные модели можно пересоздать генератором:
`java tools/AssetGen.java` (JDK 21) — он же рисует карты, фишки, сукно и скины по умолчанию.

## Рулетка и слоты (задел)

* `game/roulette` — европейское колесо (порядок секторов для анимации), все типы ставок с выплатами, расчёт раунда.
* `game/slots` — машина из конфигурации: барабаны с весами, линии, wild/scatter, таблица выплат, оценка RTP.
* Общие слои уже готовы: экономика (`economy.Economy`), крупье (`dealer.DealerDirector`/`DealerRoster`), рассадка, синхронизация.
  Для рулетки остаётся добавить блок стола + рендер колеса по образцу `BlackjackTable`/`TableRenderer`.

## Сборка и проверка

```powershell
.\tools\build.ps1 build            # jar в build/libs, плюс проверка правил (rulesTest)
.\tools\build.ps1 runShowcaseServer   # строит демо-зал со всеми столами в run-server/world
.\tools\build.ps1 runShowcaseClient   # открыть демо-зал в клиенте (мир run/saves/CasinoTest)
```

`rulesTest` прогоняет раздачи с заранее известными картами для всех вариантов (выплаты 3:2, дабл/сплит, ставки за спиной,
страховка, дилер 22, общая раздача Infinite, отмена раунда с возвратом), рулетку и слоты.
