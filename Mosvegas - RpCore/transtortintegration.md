# Интеграция транспорта с Mosvegas Core 0.0.3

Minecraft 1.20.4, Fabric, Java 17; публичный API версии 1. Этот документ намеренно называется `transtortintegration.md`, как в задании.

Ядро предоставляет готовые проверки, но подключить их нужно в серверных обработчиках самого транспорта. Клиентский запрет кнопки не является защитой. Перемещение пешком и проезд через город ядро не ограничивает.

## Slim Vehicle (MosVegas - Transport)

С версии 0.2.11 мод машин Slim Vehicle вызывает все проверки из таблицы ниже, если ядро установлено (`compat/MosvegasCompat` и `MosvegasZones`). Поведение:

- `vehicle_place` — машина не ставится; предмет не тратится, сущность и ключ не появляются.
- `vehicle_enter` — посадка отклоняется до проверки замка и двери.
- `vehicle_use` — снаружи зона работает как стена: шаг, после которого кузов задел бы зону, отменяется, машина стоит у границы без урона и может сдать назад. Внутри зоны (зону создали вокруг машины или отозвали доступ) газ и руль не действуют, держится тормоз, двигатель не заводится. Проверка повторяется при переходе кузова в другие блоки и не реже раза в секунду.
- `containers` — багажник и бардачок не открываются; `vehicle_damage` — выстрелы и взрывы не повреждают машину; `terrain` — машина не сносит хрупкие блоки.

Операторы уровня 3 и обладатели `mosvegas.zone.bypass.<флаг>` проходят все зоны, поэтому запреты проверяются обычным игроком. Игровые тесты: в проекте машин `.\gradlew.bat runGametest -PvehicleTests -PzoneTests`.

## Зависимость

В Gradle транспортного мода подключите собранный `mosvegas-core-0.0.3.jar` через `modCompileOnly files(...)`. Для разработки и запуска он также должен присутствовать среди загруженных модов. Для обязательной интеграции добавьте в `fabric.mod.json`:

```json
"depends": { "mosvegas_core": ">=0.0.3", "minecraft": "~1.20.4", "fabricloader": ">=0.15.0" }
```

Классы API используют Yarn 1.20.4+build.3. Loom переназначает имена Minecraft при использовании других mappings; не копируйте исходники Minecraft-классов между проектами. При необязательной зависимости изолируйте код адаптера и загружайте его только после `FabricLoader.getInstance().isModLoaded("mosvegas_core")`.

## Точки подключения

| Действие машины | Метод | Флаг зоны |
|---|---|---|
| Сесть водителем или пассажиром | `TransportAccess.canEnter(player, vehicle)` | `vehicle_enter` |
| Запустить двигатель, взять управление, дистанционно управлять | `TransportAccess.canUse(player, vehicle)` | `vehicle_use` |
| Создать/достать машину из гаража | `TransportAccess.canPlace(player, world, spawnBox)` | `vehicle_place` |
| Открыть багажник | `TransportAccess.canOpenStorage(player, vehicle)` | `containers` |
| Нанести урон машине | `TransportAccess.canDamage(attacker, vehicle)` | `vehicle_damage` |
| Разрушить блок тараном или взрывом | `ZoneAccess.canModifyTerrain(world, blockPos)` | `terrain` |
| Поставить/убрать блок действием игрока | `ZoneAccess.can(player, world, blockPos, ZoneAction.BUILD)` | `build` |

`TransportAccess` проверяет весь bounding box транспорта, в том числе пересечение границы зоны. Проверка ограничена 4096 блоками; нечисловые координаты, пустой или чрезмерный bounding box возвращают `false`. Проверки не загружают чанки. Для обычного автомобиля это десятки проверок индексированных регионов, а не обход всех зон.

```java
import ru.mosvegas.core.api.TransportAccess;
import ru.mosvegas.core.api.ZoneAccess;

// Выполнять внутри server.execute(...), до посадки и других изменений.
if (!TransportAccess.canEnter(player, car)) {
    player.sendMessage(Text.literal("Здесь нельзя садиться в транспорт."), true);
    return;
}
// Далее проверка ключей/владельца/места и штатная посадка вашего мода.
player.startRiding(car);

// До списания денег, расходования предмета или создания сущности:
if (!TransportAccess.canPlace(player, world, proposedBoundingBox)) return;

// До каждого разрушения блока; проверять именно цель, а не только центр машины.
if (!ZoneAccess.canModifyTerrain(world, impactedBlock)) return;
```

При непрерывном управлении перепроверяйте `canUse` при смене зоны/периодически на сервере и при каждом важном действии, иначе уже севший игрок сохранит доступ после отзыва. Не используйте `vehicle_enter` для запрета пересечения границы: этот флаг относится к посадке. Для сохранения свободного проезда не отключайте двигатель на границе, если запрет относится только к посадке или созданию машины.

Для тарана игрока применяйте обычный серверный `DamageSource` с водителем в качестве атакующего. Ядро перехватывает стандартный PvP-урон. Если мод напрямую изменяет здоровье, перед этим отдельно проверяйте `ZoneAction.PVP` в точках водителя и жертвы. Для бортового оружия проверяйте `SHOOT` до расхода патронов и создания снаряда; при попадании — `SHOOT` в месте жертвы, а для PvP ещё `PVP` у стрелка и жертвы. Проверка только в момент выстрела не защищает от стрельбы снаружи в безопасную зону.

Нельзя доверять UUID/фракции/координатам из клиентского пакета. Берите отправителя из server network handler, сущность — из серверного мира, проверяйте расстояние, ключи и принадлежность машины. Ядро отвечает за зоны, а транспорт — за владение и валидность своих пакетов. Для автономного транспорта или неизвестного атакующего передавайте `null` в `canDamage`/`ZoneAccess.can`: доступ `members` такому источнику не выдаётся.

## Внешние фракции

Встроенная фракция берётся из `DataStore.player(uuid).faction` и обновляется без кеширования членства. Внешний мод может добавить собственный провайдер один раз при инициализации:

```java
ZoneAccess.registerFactionProvider(player -> {
    // Только быстрые серверные данные, без сетевых запросов и чтения диска.
    return yourFactionService.getFactionIds(player.getUuid()); // Set<String>
});
```

ID должны совпадать с ID в командах (`police`, `medics` и т. п.). Ошибка провайдера не выдаёт доступ; она логируется один раз за серверную сессию. Несколько провайдеров объединяются с членством встроенных фракций.

## Пример служебного гаража

```mcfunction
/mosvegas zone flag police_garage vehicle_enter members
/mosvegas zone flag police_garage vehicle_use members
/mosvegas zone flag police_garage vehicle_place members
/mosvegas zone flag police_garage vehicle_damage deny
/mosvegas zone flag police_garage containers members
/mosvegas zone grant police_garage faction police vehicle_enter
/mosvegas zone grant police_garage faction police vehicle_use
/mosvegas zone grant police_garage faction police vehicle_place
/mosvegas zone grant police_garage faction police containers
```

## Проверка адаптера после появления мода транспорта

1. Гражданин, полицейский и лично добавленный игрок проверяют посадку, управление и багажник.
2. Машина стоит центром снаружи, но частью кузова внутри закрытой зоны: создание и посадка должны учитывать пересечение.
3. Отозвать фракцию/личный доступ у сидящего водителя; повторный управляющий пакет должен перепроверить права.
4. Создание машины с запретом не расходует предмет и деньги и не оставляет сущность.
5. Таран и взрыв снаружи не повреждают блоки города и игроков в зоне без PvP.
6. Проверить перезапуск, два измерения, наложение зон и разрешённую обычную езду.

До подключения этих вызовов кастомный транспорт не считается автоматически защищённым. Сам API и проверка пересечения границ покрыты серверными тестами ядра.
